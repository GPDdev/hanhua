# 影视

输入本地视频文件或只含剧集的目录。程序用 FFprobe 查看音轨、字幕与时长，优先选择已有的简中与普通话。与视频同名的外挂字幕可用 .srt、.ass、.ssa、.vtt，语言写在文件名中，例如 Movie.en.srt 和 Movie.zh-Hans.srt。显式声明语言的字幕优先于猜测。

无原文字幕时，本机 faster-whisper 生成带时间轴的对白。画面识字独立进行，识别到的标牌和片头可显示在双语 ASS 的画面文字位置。保持人物称谓和说话风格。检查画面文字与硬字幕误识和重复，尤其是滚动字幕、花体字、双人抢话及极短镜头。若作品需要修改译文，使用 submit 重新提交相关 ID，再 build。

普通话使用本机安装的中文通用音色，同一角色在同一部影片中保持同一分配。源字幕没有角色名时，利用本地说话人分离模型估计。语音按原台词的起止时刻混入。优先采用标记为音乐和音效的独立音轨，否则尝试分离混合音轨，分离失败或对白残留较强时改用原声压低的中文旁白。report.json 标明采用的方式。

交付同名的 .zh-Hans.srt、.bilingual.ass 和 .zh-Hans.mkv。中文音轨和双语字幕默认选中。核对输出轨道、时长，并播放文件的开头和含对白的片段。无对白的作品可能只生成有意义的字幕和原轨。长片中途停止后，使用原命令与原输出路径继续，已提交译文、完成的集和已合成的台词会复用。画面 OCR 每处理约三十秒影片保存一次进度。单集出现错误时继续处理其余各集，再用该集原路径及对应的 --out 单独重试。
