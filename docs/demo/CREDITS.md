# 演示素材署名

## 游戏《The Question》

`the-question-en.jpg`、`the-question-zh.jpg`、`opening-en.jpg`、`opening-zh.jpg` 是 Ren’Py 8.5.3 实际运行该示例的截图，已缩放并转为 JPEG。测试副本保留了随游戏提供的简中，特意留空两句开场对白，用于检验补译。两张选项图分别摄于补丁还原后和安装后，两张开场图分别摄于安装前和安装后。

剧本原作 mikey (ATP Projects)，改写 Lore。角色美术 Deji，原角色美术 derik。背景美术 Mugenjohncel，原背景美术 DaFool。游戏音乐 Alessio。已有的简中译文来自 SDK 随附的简体中文本地化。截图中的游戏及美术归各原作者；Ren’Py 的授权说明将演示美术列为由相应作者按相同条款发布。MIT 授权与免责条款随本仓库附上。[原作与署名](https://github.com/renpy/renpy/tree/master/the_question) ｜ [所用 SDK](https://www.renpy.org/release/8.5.3) ｜ [Ren’Py 授权说明](https://www.renpy.org/doc/html/license.html) ｜ [MIT 条款](../../LICENSE)

## 电影《Elephants Dream》

(c) copyright 2006, Blender Foundation / Netherlands Media Art Institute / www.elephantsdream.org

导演 Bassam Kurdali。原片及截取的画面、声音按 Creative Commons Attribution 2.5 Generic（CC BY 2.5）使用。原作者对电影片段的署名要求见项目公告。[官方授权与署名](https://orange.blender.org/blog/creative-commons-license-2/) ｜ [CC BY 2.5](https://creativecommons.org/licenses/by/2.5/) ｜ [原片下载](https://orange.blender.org/download/)

| 文件 | 制作方式 |
| --- | --- |
| `elephants-dream-original.mp4` | 从官方 720 像素宽的电影文件截取 00:45 至 01:08，转为适合浏览器播放的 H.264/AAC，保留英语原声。[所用原片文件](https://download.blender.org/ED/elephantsdream-720-h264-st-aac.mov) |
| `elephants-dream-zh.mkv` | 将上述无字幕 MP4 输入 hanhua，由本机听译、当前 Codex 会话翻译、语音合成和混音生成。与输入片段相比，原图像流和英语音轨的压缩包数据 SHA-256 各自一致。 |
| `elephants-dream-zh.mp4`、`elephants-dream.jpg` | 取 MKV 的默认普通话音轨，将其双语 ASS 渲染到画面以便浏览器播放。预览图截自该 MP4 的第 7.75 秒。 |
| `elephants-dream.zh-Hans.srt`、`elephants-dream.bilingual.ass` | 本次技能构建输出的两份字幕。原样保留第 6.00、8.25、12.75 秒起的三处画面误识，便于评估 OCR 的实际表现。 |

电影节选、汉化预览及其字幕按 [CC BY 2.5](https://creativecommons.org/licenses/by/2.5/) 提供。上述处理和中文配音由本项目完成。
